# Design System

## Paleta de Cores

### Light Mode
- Primaria: #6366F1 (Indigo 500)
- Primaria Light: #A5B4FC (Indigo 300)
- Primaria Dark: #4338CA (Indigo 700)
- Secundaria: #14B8A6 (Teal 500)
- Acento: #F59E0B (Amber 500)
- Background: #F9FAFB (Gray 50)
- Surface: #FFFFFF (White)
- Texto primario: #111827 (Gray 900)
- Texto secundario: #6B7280 (Gray 500)
- Sucesso: #10B981 (Emerald 500)
- Warning: #F59E0B (Amber 500)
- Erro: #EF4444 (Red 500)
- Info: #3B82F6 (Blue 500)

### Dark Mode
- Background: #111827 (Gray 900)
- Surface: #1F2937 (Gray 800)
- Texto primario: #F9FAFB (Gray 50)
- Texto secundario: #9CA3AF (Gray 400)

## Tipografia

**Fonte principal:** Inter
**Fonte monospace:** JetBrains Mono (para SQL)

### Escala Tipografica
- H1: 32px, Bold (700), Line Height 1.2
- H2: 24px, SemiBold (600), Line Height 1.3
- H3: 20px, SemiBold (600), Line Height 1.4
- H4: 18px, Medium (500), Line Height 1.4
- Body: 16px, Regular (400), Line Height 1.5
- Body Small: 14px, Regular (400), Line Height 1.5
- Caption: 12px, Regular (400), Line Height 1.4
- Button: 14px, SemiBold (600), Line Height 1

## Componentes UI

### Botoes
- Estilo: Filled
- Border radius: 8px
- Tamanhos: Small (32px), Medium (40px), Large (48px)

### Cards
- Elevacao: shadow-sm
- Border radius: 12px

### Inputs
- Estilo: Outlined
- Border radius: 8px
- Labels: Floating

### Outros
- Modais: Border radius 16px, overlay 50%
- Toasts: Bottom-center, 3s
- Tabs: Underline
- Lists: Border separator

## Iconografia

**Biblioteca:** Ionicons
**Estilo:** Outlined
**Tamanho padrao:** 24px

## Espacamento

**Base unit:** 4px
**Escala:** xs=4, sm=8, md=16, lg=24, xl=32, xxl=48

## Animacoes

**Nivel:** Moderado
**Duracao:** 200ms
**Easing:** ease-out
**Loading:** Skeleton

## Tom de Voz

**Formalidade:** Profissional mas acessivel
**Tratamento:** Voce
**Exemplos:** "Adicione uma nova tabela", "Sua exportacao esta pronta"
