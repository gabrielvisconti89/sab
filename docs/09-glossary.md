# Glossario

## Termos do Dominio

**Projeto:** Conjunto de especificacoes e arquitetura de um software a ser desenvolvido.

**Tabela:** Estrutura de banco de dados que armazena registros de uma entidade.

**Coluna:** Campo individual dentro de uma tabela, com tipo de dado e constraints.

**Relacionamento:** Conexao entre duas tabelas atraves de foreign keys.

**Foreign Key (FK):** Coluna que referencia a primary key de outra tabela.

**Primary Key (PK):** Identificador unico de cada registro em uma tabela.

**Migration:** Arquivo de codigo que descreve alteracoes no schema do banco de dados.

**Schema:** Estrutura completa do banco de dados (tabelas, colunas, indices, relacionamentos).

**Timestamp:** Colunas created_at e updated_at que registram datas de criacao e atualizacao.

**Soft Delete:** Tecnica de "exclusao suave" usando coluna deleted_at ao inves de remover o registro.

**MCP:** Model Context Protocol - protocolo para conectar o Claude a fontes de documentacao.

**claude.md:** Arquivo indice que fornece contexto do projeto para uso com IA.

**Tailwind CSS:** Framework de CSS utilitario usado para estilizacao.

**Ionic:** Framework para desenvolvimento de aplicativos mobile hibridos.

**Capacitor:** Runtime que permite apps web rodarem nativamente em iOS/Android.

**Checklist:** Lista de verificacao com itens a serem concluidos, usada para acompanhar progresso.

**Front-end First:** Abordagem de desenvolvimento onde toda a interface e criada antes do back-end.

## Tipos de Dados SQL

**VARCHAR:** String de tamanho variavel.

**TEXT:** String longa sem limite definido.

**INT/BIGINT:** Numero inteiro.

**DECIMAL:** Numero com precisao decimal.

**BOOLEAN:** Verdadeiro ou falso.

**TIMESTAMP:** Data e hora.

**JSON:** Dados estruturados em formato JSON.

**ENUM:** Lista de valores predefinidos.
